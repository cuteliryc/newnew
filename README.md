# Moneyball — аналитическая система маркетинга

Как в «Человеке, который изменил всё»: решения принимаются не по ощущениям и не по красивым метрикам
(CTR, лайки, дешёвый клик), а по тому, что приносит деньги. Система находит, что у вас недооценено,
куда переложить бюджет, какой креатив и текст делать дальше и почему — и учится на каждом результате.

**Основная часть работает без ИИ**: формулы, планировщик, генератор баннеров, оценка PR-идей.
GPT-агенты — дополнение: интерпретируют расчёты, пишут тексты, смотрят баннеры. Работают через
вашу подписку ChatGPT (вход в браузере), без платного API.

## Что умеет

| Команда | Что делает | ИИ |
|---|---|---|
| `weekly` | Отчёт недели: воронка в деньгах, бюджет по предельной отдаче, какие признаки креативов работают, слова, конкуренты, эксперименты, очередь гипотез | нет |
| `plan <запрос>` | План 360 под задачу: экономика (сколько можно платить за клиента и заявку), проверка оффера, каналы с учётом доступности и права в РФ, бюджет (деньги для платных каналов, часы для холодки), креатив, контент, удержание, идеи для СМИ, похожие кейсы и тесты из них, календарь на 4 недели | нет |
| `banners <бриф>` | Собирает баннеры по компоновкам (сетка, трети, золотое сечение, центр, Z), проверяет контраст и долю текста, выбирает компоновки и углы по вашим прошлым результатам | нет (`--review` — ревью GPT по картинке) |
| `pr ideas / pr score` | Идеи для попадания в СМИ по шаблонам реальных кейсов и форма оценки идеи | нет |
| `abtest`, `sample-size` | Сравнить два варианта; сколько нужно показов для теста | нет |
| `agent run <имя>` | GPT-агент: стратег, креативный директор, копирайтер, разведчик конкурентов, арт-директор, PR-стратег | да |

## Онлайн-версия

**https://cuteliryc.github.io/newnew/** — та же система в браузере: отчёт недели по загруженным таблицам, план 360,
баннеры, оценка и генерация PR-идей, калькуляторы тестов, база кейсов. Python работает прямо в браузере (Pyodide),
ваши таблицы никуда не отправляются. GPT-агенты — только в версии для компьютера.

Сайт собирается из папки `docs/`. После изменений в коде: `python3 tools/build_site.py` и коммит.
Включить один раз: Settings → Pages → Source: Deploy from a branch → ветка `claude/tender-einstein-eu1d2k`, папка `/docs`.

## Установка

```bash
git clone <репозиторий> && cd newnew
python3 -m pip install -r requirements.txt     # numpy, Pillow, pytest
python3 -m moneyball init                       # папки data/, briefs/, requests/, ideas/ и config.json
python3 -m moneyball demo                       # прогон на вымышленных данных — посмотреть, как выглядит результат
```

Для GPT-агентов (по желанию):

```bash
npm i -g @openai/codex        # официальный CLI от OpenAI
codex login                   # откроется браузер — войдите в свой аккаунт ChatGPT
python3 -m moneyball login    # проверить вход
```

## Еженедельный цикл

1. **Понедельник — данные.** Выгрузите в `data/`:
   - `funnel.csv` — по неделям и каналам: расход, часы ручной работы, показы/касания → клики/ответы → заявки → офферы → сделки, выручка;
   - `creatives.csv` — каждый креатив с тегами (хук, угол, формат, компоновка…) и результатами;
   - `channel_weeks.csv` — недельный расход и выручка по платным каналам (для модели бюджета);
   - `competitors.csv` — снимок библиотек объявлений конкурентов (Meta Ad Library, VK, Google Transparency);
   - `experiments.csv` — тесты: варианты, план выборки, результаты;
   - `content.csv` — публикации в соцсетях (охват, пересылки, сохранения, заявки) — найти «залёты»;
   - `orders.csv` — заказы клиентов — повторные продажи, LTV, сегменты;
   - `pr_log.csv` — прогноз PR-идеи до запуска и факт после — проверка формы оценки.
2. **Расчёт:** `python3 -m moneyball weekly` (или `weekly --agents` — с GPT-агентами).
   Результат: `outputs/<дата>/report.md`.
3. **Решения:** берёте 1–3 решения и тесты из очереди. Записываете в `data/decisions.csv`.
4. **Креативы:** `python3 -m moneyball banners briefs/<бриф>.json --register` — новые баннеры
   уже размечены и попадут в анализ, когда вы допишете их результаты.
5. **Через неделю** результаты возвращаются в данные — система пересчитывает, что работает.

## Настройка под задачу

`requests/*.json` — запрос для планировщика: задача (leads / sales / awareness / retention / pr),
модель бизнеса, отрасль, аудитория, рынок, **какие кабинеты доступны**, бюджет, средний чек, маржа.
Пример — `templates/request.json`.

`config.json` — ваша маржа, стоимость часа, валюта, какой результат считать главным для креативов
(`creatives.result`: leads / deals / clicks), параметры модели бюджета, размеры баннеров, GPT-настройки.

## Агенты

Агент — это файл `agents/<имя>.md`: шапка (какие расчёты и знания ему дать, запускать ли еженедельно,
какую модель) и инструкция. **Чтобы добавить агента — скопируйте `templates/agent.md` в `agents/` и опишите роль.**
Код менять не нужно. Агенты возвращают гипотезы в JSON — они автоматически попадают в `data/hypotheses.csv`
и встают в очередь по ожидаемой ценности.

Подключить другой сервис (не ChatGPT) — `config.json` → `llm.backend: "openai_api"` и `base_url`
любого OpenAI-совместимого API (OpenRouter, DeepSeek и т.п.), ключ в переменной окружения.

## Откуда формулы

`knowledge/principles.md` — правила с метками силы доказательств (сильно / средне / вендор / миф).
`reports/` и `research_notes/` — полное исследование с источниками.
`knowledge/cases/` — 160 кейсов с источниками и меткой силы доказательств: e-com/DTC (40), B2B и услуги (40),
РФ/СНГ (35), попадание в СМИ и анти-примеры (45). `knowledge/channels.json` — 24 канала: для чего подходят,
доступность из РФ, минимальный бюджет, правовые флаги (проверено в октябре 2026).

## Честные ограничения

- Корреляция по креативам и словам — подсказка, что тестировать, а не доказательство. Платформы показывают
  разные креативы разным людям; победителей подтверждайте split-тестом.
- Модель бюджета наблюдательная и требует ≥12 недель данных с вариацией расхода; перед крупным
  переносом бюджета подтвердите эффект lift- или гео-тестом.
- Стартовые пороги (целевой CAC = 1/3 прибыли с клиента, 10% на разведку, 30 заявок на вывод по каналу)
  — допущения, а не законы. Их надо заменить вашими данными.
- Золотое сечение и правило третей в генераторе — варианты для проверки, а не «правильный дизайн»:
  исследования не подтверждают их влияния на рекламу.
- Кейсы в базе собраны из открытых источников; у каждого указана сила доказательств. Цифры из кейсов
  площадок и агентств (метка vendor) — ориентир, не гарантия.
